# Contributing to Duplicate File Cleaner

Thank you for your interest in contributing! This guide will help you get started.

## How to Contribute

### Reporting Bugs

If you find a bug, please [open an issue](https://github.com/yourusername/duplicate-cleaner/issues/new?template=bug_report.md) and include:

- A clear description of the problem.
- Steps to reproduce the behavior.
- Your Python version and operating system.
- Any relevant error messages or logs.

### Requesting Features

Have an idea for a new feature? [Open a feature request](https://github.com/yourusername/duplicate-cleaner/issues/new?template=feature_request.md) and describe:

- The problem your feature would solve.
- Your proposed solution.
- Any alternatives you have considered.

### Submitting Pull Requests

1. Fork the repository and create a new branch from `main`.
2. Make your changes with clear, descriptive commit messages.
3. Ensure your code follows the existing style (PEP 8).
4. Test your changes locally before submitting.
5. Open a pull request referencing any related issues.

### Code Style

- Follow [PEP 8](https://peps.python.org/pep-0008/) guidelines.
- Use clear, descriptive variable and function names.
- Add docstrings to all public functions and modules.
- Keep the project dependency-free (Python standard library only) unless a strong case is made otherwise.

### Project Structure

```
duplicate-cleaner/
  main.py          # Core duplicate detection logic and CLI
  examples/
    demo.py        # Usage examples
  .github/
    ISSUE_TEMPLATE/  # Bug report and feature request templates
```

## Questions?

Feel free to [open an issue](https://github.com/yourusername/duplicate-cleaner/issues) with any questions. We are happy to help!

Thank you for contributing!
